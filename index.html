01 核心特性

多模型智能路由为系统核心，MCP 协议对外暴露能力，像素美学与情感可视化构成交互层。

🤖 多模型智能路由 ai_router.py

依据任务类型与复杂度自动选型，覆盖 DeepSeek、OpenAI、通义千问、豆包、Kimi、Claude 六家供应商。

  • 自动故障转移至备用模型
  • SSE 流式响应
  • 复杂问题拆解为子任务的多模型协作与结果聚合

🔌 MCP 协议 backend/app/mcp

标准 MCP 工具定义，支持 HTTP + SSE，可被外部 MCP 客户端发现与调用，亦支持接入第三方 MCP 服务器。

  • chat_completion · analyze_emotion
  • translate · get_models
  • collaborative_chat

🎨 像素美学 styles/

自 PyQt5 时代延续的像素主题，CSS 自定义属性集中管理，含 ASCII 装饰与 CRT 扫描线。

  • GIF 动态背景轮播
  • 打字机消息渲染
  • GIF/静态角色图资源池

🔐 用户认证 JWT + bcrypt

Access Token 7 天 / Refresh Token 30 天，多用户数据完全隔离，配套像素风登录与注册界面。

✍️ Humanizer AI 文本检测

24 种 AI 写作模式检测与人性化改写建议，0–100% 可视化评分，规则依据 Wikipedia 写作指南。

💚 情感与记忆 ECG / 梦境 / 星图

真实心电波形（P-QRS-T）Canvas 绘制、梦境解析与符号百科、历史对话星图可视化、自我进化记忆系统。

04 快速启动

推荐统一启动器；亦可分别手动启动后端与前端。首次使用请先执行环境安装。

方式一 · 统一启动器（Windows，推荐） 
launcher.bat            :: 交互式菜单
launcher.bat setup      :: 一键安装依赖
launcher.bat dev        :: 后端 + 前端（双窗口）
launcher.bat backend    :: 仅后端 :8000
launcher.bat frontend   :: 仅前端 :5173
launcher.bat tauri      :: Tauri 桌面窗口
launcher.bat test       :: 测试模式
launcher.bat prod       :: 生产模式
launcher.bat stop       :: 释放 8000/5173 端口

:: PowerShell 下建议：cmd /c launcher.bat dev
方式二 · 手动启动（后端） 
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
方式三 · 手动启动（前端，新终端） 
cd frontend
npm install
npm run dev
NOTE  首次运行前需配置密钥：cd backend → 复制 .env.example 为 .env → 填入各模型供应商 API Key。 .env 已被 .gitignore 排除，不会入库。
