## ✨ 核心改进

### 1. **真实心电图波形**

#### 波形组成
完整模拟真实心电图的5个关键波段：

```
    R波（主峰）
      /\
     /  \
    /    \___
   /         \    T波
P波          \  /\
  /\          \/  \
 /  \________/     \______
/              Q    S波
               \  /
                \/
```

- **P波** (8ms): 心房去极化，小而圆的波形
- **QRS复合波** (35ms峰值): 心室去极化，主要 spike
  - Q波: 小幅下降 (-5)
  - R波: 主峰上升 (+35)
  - S波: 快速下降 (-12)
- **T波** (12ms): 心室复极化，中等幅度

## 🔧 技术细节

### Canvas 渲染
- **尺寸**: 300×80px (逻辑尺寸)
- **帧率**: ~60fps (requestAnimationFrame)
- **数据点**: 最多300个点
- **线宽**: 2.5px，圆角端点

### 性能优化
1. **数据点管理**: 保持固定数量，自动移除旧数据
2. **局部重绘**: 只清除必要区域
3. **平滑过渡**: 避免频繁的状态突变

### 响应式设计
- Canvas 宽度自适应 (`width: 100%`)
- 高度固定 80px
- 移动端友好

### 修改情感配置

在 `ECGStatusBar.tsx` 中编辑 `EMOTION_CONFIG`:

```typescript
const EMOTION_CONFIG: Record<string, { 
  heartRate: number;   // 心率 (60-120)
  color: string;       // 十六进制颜色
  intensity: number;   // 波形强度倍率 (0.5-2.0)
}> = {
  // 添加新的情感类型
  love: { heartRate: 95, color: '#ff1493', intensity: 1.4 },
};
```

```typescript
// P波幅度
```
