# 星图功能使用指南

## 🌟 快速开始

### 访问星图页面

1. **启动应用**
   ```bash
   # 终端 1 - 后端
   cd backend
   .venv\Scripts\activate
   uvicorn app.main:app --reload --port 8000

   # 终端 2 - 前端
   cd frontend
   npm run dev
   ```

2. **打开浏览器**
   - 本地访问: http://localhost:5173
   - 公网访问: http://7b8aeee0.r7.cpolar.top (通过 cpolar)

3. **导航到星图**
   - 点击左侧导航栏的 **"✨ 星图"** 按钮

## 🎮 功能说明

### 1️⃣ 主显示区

```
┌──────────────────────────────────────┐
│                                      │
│         [星图 GIF 动画]               │
│                                      │
│  ┌────────────────────┐             │
│  │ stars_867_Sol      │ ← 星图名称  │
│  │ 7 / 11            │ ← 当前索引   │
│  └────────────────────┘             │
└──────────────────────────────────────┘
```

**特性**:
- ✨ 自动播放 GIF 动画
- 📐 保持原始宽高比
- 🎯 居中显示，自适应容器大小
- 💫 平滑过渡动画

---

### 2️⃣ 控制按钮

```
[◀ 上一张]  [⏸ 暂停]  [▶ 播放]  [⛶ 全屏]
```

**功能**:
- **◀ 上一张**: 切换到前一个星图
- **⏸/▶ 播放/暂停**: 控制自动轮播（8秒间隔）
- **⛶ 全屏**: 进入沉浸式全屏模式

**提示**: 
- 手动切换时会自动暂停自动播放
- 点击"播放"恢复自动轮播

---

### 3️⃣ 缩略图导航

```
[thumb1] [thumb2] [thumb3] [thumb4] ... →
```

**操作**:
- 👆 **点击缩略图**: 立即切换到对应星图
- 🔍 **滚动查看**: 左右滑动查看所有缩略图
- ✨ **高亮显示**: 当前选中的缩略图有金色边框

---

### 4️⃣ 全屏模式

**进入全屏**:
- 点击 "⛶ 全屏" 按钮

**退出全屏**:
- 按 `ESC` 键
- 或点击右上角 "✕ 退出全屏" 按钮

**全屏效果**:
- 🌌 纯黑背景，沉浸式体验
- 🖼️ 星图最大化显示
- 🎮 隐藏控制栏（减少干扰）

## 🎨 视觉效果

### 毛玻璃效果

在设置中开启"毛玻璃效果"后：
- 信息叠加层会有模糊背景
- 控制栏会有半透明磨砂效果
- 整体更有层次感和现代感

**开启方式**:
1. 点击左侧 "⚙️ 设置"
2. 找到 "显示" 分组
3. 点击 "毛玻璃效果" 按钮

## 💡 使用技巧

### 最佳观赏体验

1. **全屏模式**: 获得最沉浸的星空体验
2. **关闭毛玻璃**: 让星图更清晰可见
3. **暗光环境**: 在较暗的环境中观看效果更佳
4. **大屏幕**: 使用大屏幕显示器或投影

### 快捷操作

- **快速浏览**: 使用缩略图快速定位
- **暂停欣赏**: 看到喜欢的星图时暂停自动播放
- **分享时刻**: 全屏模式下截图分享

### 性能优化

- **首次加载**: GIF 文件较大，首次加载可能需要几秒
- **内存管理**: 同时打开多个标签页可能占用较多内存
- **网络环境**: 公网访问时注意流量消耗

## 🔧 故障排除

### 问题1: 星图无法加载

**症状**: 显示"加载中..."或空白

**解决方案**:
1. 检查后端服务是否运行
2. 确认 `resource/Star Map/` 目录存在
3. 刷新页面重试

### 问题2: GIF 不播放

**症状**: 显示静态图片

**解决方案**:
1. 检查浏览器是否支持 GIF
2. 尝试清除浏览器缓存
3. 更换浏览器测试

### 问题3: 缩略图不显示

**症状**: 缩略图区域空白

**解决方案**:
1. 检查网络连接
2. 查看浏览器控制台错误
3. 重启前端开发服务器
