# 历史对话功能使用指南

## 📋 功能概述

已成功添加完整的历史对话管理功能，支持查看、删除和加载历史对话记录。

---

## ✨ 核心功能

### 1. **查看历史对话** 📜

#### 访问方式
- 点击左侧导航栏的 **"📜 历史"** 按钮
- 进入历史对话面板

#### 显示内容
每条历史记录包含：
- 💬 **用户消息预览**: 显示前50个字符
- 🕐 **时间戳**: 相对时间（如"5分钟前"）或具体日期
- 🤖 **模型名称**: 使用的AI模型
- 😊 **情感标签**: 对话时的情感状态（如果有）

#### 列表特性
- ✅ 按时间倒序排列（最新的在前）
- ✅ 分页显示（每页20条）
- ✅ 滚动加载更多
- ✅ 悬停高亮效果

---

### 2. **分页浏览** 📄

#### 分页控制
```
[◀ 上一页]  1 / 5  [下一页 ▶]
```

- **上一页/下一页**: 切换页面
- **页码显示**: 当前页 / 总页数
- **自动禁用**: 首页禁用"上一页"，末页禁用"下一页"

#### 性能优化
- 每页加载20条记录
- 按需加载，避免一次性加载大量数据
- 平滑滚动体验

---

### 3. **删除对话** 🗑️

#### 删除单条
1. 找到要删除的对话
2. 点击右侧的 **🗑️** 按钮
3. 确认删除操作

#### 安全机制
- ⚠️ 删除前有确认对话框
- ❌ 防止误删重要对话
- 🔄 删除后自动刷新列表

---

### 4. **加载对话** 📥

#### 当前实现
点击历史对话项会：
- 显示对话详情提示框
- 展示用户消息和时间信息

#### 未来扩展
可以增强为：
- 将历史对话加载到当前聊天窗口
- 恢复完整的对话上下文
- 继续之前的对话

## 📊 时间格式化逻辑

### 智能显示

| 时间范围 | 显示格式 | 示例 |
|---------|---------|------|
| < 1小时 | X分钟前 | "5分钟前" |
| < 24小时 | X小时前 | "3小时前" |
| > 24小时 | 月/日 时:分 | "5月3日 14:30" |

### 实现代码

```typescript
const formatTime = (dateStr: string) => {
  const date = new Date(dateStr);
  const now = new Date();
  const diff = now.getTime() - date.getTime();
  
  if (diff < 3600000) {
    return `${Math.floor(diff / 60000)}分钟前`;
  }
  if (diff < 86400000) {
    return `${Math.floor(diff / 3600000)}小时前`;
  }
  return date.toLocaleDateString('zh-CN', {
    month: 'short',
    day: 'numeric',
    hour: '2-digit',
    minute: '2-digit',
  });
};
```
